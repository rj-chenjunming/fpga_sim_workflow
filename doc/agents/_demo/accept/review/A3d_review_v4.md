## 2 事项 1 · 预置段改动是不是"零代价等价替换"（本轮最关键）

### ① `set_data_ram` 是否真的零总线读？——**是（我回原文件核实）**

`TB/AGENTS/I2C-Agent/i2c_s.sv:419-421`（md5 `81d1372262a6cacac88352a571934390`）：
```systemverilog
function void putbpWord (input bit[23:0] address, bit8 dataWord);
this.bfm.ramArray[address]   = dataWord;
endfunction
```
- 它是 **`function`**（不是 `task`）⇒ SV 语义上**不可能消耗仿真时间**（函数体内不能有 `#`/`@`/`wait`）；
- 函数体**只有一次本地 `ramArray` 赋值**，**无任何 BFM/接口/总线动作**；
- 调用链：`set_data_ram`（`pcie_sequence.sv:887-898`）→ `i2c_slv[n].putbpWord(addr+i, data_rand)`；其体内其余语句为 `dom_chn_en` 读取、`$display("chn[...]")`、以及条件写本地 `data_ram[n][0][...]` —— **均不是总线访问** ✓
⇒ **`set_data_ram` 零总线读、零仿真时间、零墙钟** ✓（作者称述**成立**）。**"砍轮数"确实没有削弱从模型预置的代价面**。

### ② 索引语义有没有变？——**对本用例断言范围等价；对覆盖面是削减（已登记 U6）**

索引约定（我从库源码读出）：`n = 控制器号 × 4 + 通道号`
- `set_data_ram(n,…)`：`i2c_slv[n].putbpWord(...)`；`chn_ent_mp = dom_chn_en[(n/`DOME_CHN_NUM`)][(n%`DOME_CHN_NUM`)]` ⇒ **n 直接就是 `i2c_slv[]` 的下标**；
- `polling_data_chk(n,…)`：`base_addr = `DOME_RTC_ADDR + `DOME_RTC_OFFSET*(n/4) + 0x200 + 0x80*(n%4)` ⇒ 同一约定（n/4=控制器、n%4=通道）。

| | v3 | v4 |
|---|---|---|
| `polling_data_chk` 覆盖窗口 | `i` = 0..31 ⇒ **32 个窗口**（控制器 0~7 × 通道 0~3） | `polling_data_chk(0,1)` ⇒ **1 个窗口**（控制器 0、通道 0） |
| `set_data_ram` 覆盖 `i2c_slv[]` 号段 | `i2c_slv[0..31]`（32 个模型） | `i2c_slv[0..3]`（**控制器 0** 的通道 0~3） |
| 本用例断言目标（`0x403c` = 控制器 0 的 `i2c_sta`）是否被覆盖 | 是 | **是**（n=0..3 恰为控制器 0 的 4 个通道） |

⇒ **判定**：**不是"覆盖同一批从模型"** —— v4 只覆盖 `i2c_slv[0..3]`，v3 覆盖 `i2c_slv[0..31]`；被去掉的是**控制器 1~7 的 28 个模型**。
**但就本用例的断言范围而言等价**：用例只断言控制器 0 的 `i2c_sta` 序列（并在 `U1` 声明**不断言 polling 数据窗内容**）⇒ 控制器 1~7 的预置数据**不参与任何判据**。
⇒ **结论：属"有据的覆盖削减"，且已在 `U6` 明确登记（见 §5），不是偷偷削减**；对断言等价性**成立**。
