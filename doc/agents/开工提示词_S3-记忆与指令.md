## 3 S3 三片范围与验收（串行：S3a → S3b → S3c）

### S3a WM：可重建工作记忆（REV-13 §6、必测 WM-01～05）

- **唯一构造者**：新文件 `loop/host/agent_working_memory.py`（`build(ctx, node, input_data, ...) -> WorkingMemory`）。
- **唯一消费点**：`model_request.run_attempt` 把 `working_memory` 放进 `request_input`（与现有 `input_data`/`approved_experiences` 同级），并随 `AM.Attempt` 的 request 封存。
- 必须满足：
  1. **确定性**：同一明确来源重建 ⇒ 同一 `snapshot_sha256`；换资源版本 ⇒ 旧事实失效（WM-01）。
  2. **条目五类**：`observed_fact` / `human_decision` / `model_proposal` / `open_issue` / `constraint`；`proposal` 不得晋升为 fact（WM-02）；`open_issue` 复用 H1/H2b 的 `issue_id`/`follow_up`/重开规则。
  3. **载体**：`{version, availability: verified|unavailable, snapshot_sha256, entries[], unavailable[]}`；每项要么有 `value` 要么有 `input_ref`（JSON Pointer 指向**同一请求既有字段**，Host 校验存在/版本一致，禁指向 `working_memory` 自身、循环、外部未读材料）。
  4. **不重复**：已在本次 `input_data` 提供的正文不再复制（WM-05）。
  5. **预算**：强制事实/问题/约束超限 ⇒ **调用前失败**并报缺口，不截断/不抽样（WM-03）；索引不等于材料已送达（WM-04：无补读能力的后端必须预载正文）。
  6. 旧格式/缺来源 ⇒ 不标 `verified`（可 `unavailable` + 保留当前权威事实）。
- 不要做：语义压缩/总结模型、向量检索、第二套 issue 规则。

### S3b IL：指令生命周期（REV-13 §7、必测 IL-01～04）

- 落点：`agent_control` 扩 run 作用域事件（`agent_controls/` 下独立子目录，只增不改）+ `services/api.py` 两个端点
  （`GET /api/runs/{run_id}/instructions`、`POST /api/runs/{run_id}/instructions`），入参含
  `actor`/`request_id`/`expected_instruction_revision`，动作 `create|revoke|supersede`。
- 必须满足：
  1. **scope**：`attempt` / `node_rework` / `run`；"本次尝试"指**确认旧执行停止后的替代尝试**（不猜测、不跨 run 继承）；旧 `/control` 的会话内语义**保持**，不自动升级为 node/run（IL-04）。
  2. **原子性**：`supersede` 事件原子包含"旧 ID 失效 + 新条目"；同幂等键不同 payload 必须冲突（IL-02）。
  3. **接受门**：结果必须同时符合当前 generation + 指令 revision；**迟到结果只留审计**，不进入消费者（IL-03）。
  4. `accepted` / `applied` / `effective` 是**不同事实**，UI 投影只消费服务端结论（不许把 accepted 显示成 applied）。
  5. 每 run 单写者（沿用 RunManager 写权）；没有经验证的单写者协调时**拒绝**指令写入。
- 不要做：第二套业务台账、按关键词判指令冲突、命令文件（`commands/*.cmd.json`）机制。

### S3c EXP：经验分层（REV-13 §8、必测 EXP-01～03）

- 落点：`agent_memory.scope_for/experiences` 增加 v2 分支（**v1 逐值相等行为保持**，EXP-01）+ 离线迁移/校验工具（放 `loop/host/` 或 `loop/spikes/`，**不要进 `kb/`**）+ 请求记录（选中条目/适用条件/检查结果/目录指纹）。
- 必须满足：
  1. **两类适用性**：`exact_fact`（绑定资源当前内容/环境/基线，依赖逐项核验，变了就拒用）/ `general_advice`（绑定已批准节点/任务类别/环境策略/契约兼容范围，不要求整请求字节相同）。
  2. **审计指纹 ≠ 适用条件**：请求审计指纹照实记录，但**不得**用它直接判所有经验是否可复用；不用模型/关键词猜相似性。
  3. **拒用整批**：可选经验批次超预算或使必需上下文超限 ⇒ 整体不采用 + 记录候选 ID/原因；不截断、不静默取前 N 条（EXP-03）。
  4. 源完整性（路径/符号链接/sha256）与**当前事实适用性**分开检查（EXP-02）。
  5. 不自动晋升：`human` 字段只是单机元数据，**模型不得写回** `adjudication/agent_experiences.json`；审批/撤销由人做，改内容/范围必须新 revision 并重新确认。
- 不要做：学习排序、向量检索、自动记忆管理 UI。
