## 3 规格条款与逐条判读

规格原文（`doc/spec/LOOP_ORCHESTRATION_SPEC.md:119-122`）：

> **统一边界判据（R2，2026-10-22）**：无论清单写绝对路径还是相对路径，候选都先 `resolve()`
> （跟随符号链接）再判定必须落在允许根集合内（`<WORKSPACE_ROOT>`、其父、环境根），**然后**才读取/哈希；
> `..` 越界、相对符号链接逃逸、断链/循环链接与绝对越界使用**同一条**判据，不得出现第二套近似规则。
> 越界 ⇒ 该件按 `missing`/`errors` 计入并拒绝，且准入零副作用（不写 run、作业、事件）。

| # | 条款要求 | 判读 | 依据 |
|---|---|---|---|
| 1 | 绝对/相对同一条判据 | **满足**。`_artifact_path` 只把「候选集合」按绝对/相对分叉，随后统一 `_resolved_or_none` → `_inside_roots`；不存在第二个路径判定函数 | §4.2 代码、§4.5 探针 P1–P3 |
| 2 | 先 resolve（跟随符号链接） | **满足**。`candidate.resolve()`（strict=False），相对候选先拼 `<root>/<path>` / `<root>/../<path>` 再 resolve | §4.2 |
| 3 | 再判允许根集合 | **满足**。`_allowed_roots` = `{工作区根, 其父, ENV_ROOT}`，全部 resolve 后去重；`_inside_roots` 用 `==` 或 `in parents` | §4.2 |
| 4 | 不扩大允许根 | **满足**。与旧**绝对分支**的三元组逐字相同；相对分支从「无范围检查」收紧到同一三元组，属收窄 | §4.2 |

### 4.2 实现 diff（`git show e279eac -- loop/host/baseline.py`，节选判据核心）

```python
def _allowed_roots(workspace_root: Path) -> tuple[Path, ...]:
    roots: list[Path] = []
    for base in (workspace_root, workspace_root.parent, Path(P.ENV_ROOT)):
        resolved = base.resolve()
        if resolved not in roots:
            roots.append(resolved)
    return tuple(roots)

def _resolved_or_none(candidate: Path) -> Path | None:
    try:
        return candidate.resolve()
    except (OSError, RuntimeError):
        return None

def _artifact_path(workspace_root: Path, raw: Any) -> Path | None:
    ...
    candidate = Path(raw)
    if candidate.is_absolute():
        candidates: tuple[Path, ...] = (candidate,)
    else:
        candidates = tuple(base / candidate for base in (workspace_root, workspace_root.parent))
    roots = _allowed_roots(workspace_root)
    fallback: Path | None = None
    for item in candidates:
        resolved = _resolved_or_none(item)
        if resolved is None or not _inside_roots(resolved, roots):
            continue
        if fallback is None:
            fallback = resolved
        if resolved.exists():
            return resolved
    return fallback
```

```python
for base in (workspace_root, workspace_root.parent):

    if resolved.exists():

return None
```
