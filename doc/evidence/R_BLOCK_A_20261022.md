## V1 离线浏览器（安装 + 真实启动）

```bash
cd loop && .venv/bin/python spikes/browser_offline.py verify
# PASS: offline bundle platform and SHA-256 verification   (rc=0)

cd loop && .venv/bin/python spikes/browser_offline.py install
# Successfully installed greenlet-3.2.5 playwright-1.64.0 pyee-13.0.1
# FAIL: TargetClosedError: BrowserType.launch: Target page, context or browser has been closed
#   [pid][err] touch: cannot touch '/home/work/chenjunming/.local/share/applications/mimeapps.list': Read-only file system
#   [pid][err] chrome_crashpad_handler: --database is required
# rc=1（wheels 安装成功；随后的启动冒烟失败）
```

失败归因（**环境层，不是缺系统库**）：系统 `/usr/bin/google-chrome`（152.0.7977.75）在
**`$HOME` 只读**时无法启动（写入 `~/.local/share/applications/mimeapps.list` 被 EROFS 拒绝，随后 SIGTRAP）。
把 HOME/XDG 指向可写临时目录后真实启动通过：

```bash
cd loop && mkdir -p /tmp/h && HOME=/tmp/h XDG_CONFIG_HOME=/tmp/h/.config XDG_CACHE_HOME=/tmp/h/.cache \
  .venv/bin/python spikes/browser_offline.py check
# PASS: offline bundle platform and SHA-256 verification
# PASS: local browser smoke; version=152.0.7977.75; executable=/usr/bin/google-chrome   (rc=0)
```

结论：`playwright` Python 包已按离线包安装（`--no-index --require-hashes`）；浏览器真实启动**通过**，
前提是 `HOME` 可写。`libnspr4/libnss3` 等系统库缺件**未出现**（与 §36 的最小镜像情形不同）。
安装后 `tests/browser` 由「模块级 skip」变为**真实执行**；缺 `LOOP_BROWSER_EXECUTABLE` 时它们是
`error`（playwright 找不到浏览器），**不是 skip，不得当通过**。
