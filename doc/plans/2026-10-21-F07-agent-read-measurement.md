## 1 问题

Agent 历史读取（`read_view` + 事件列表）随 attempt 数、单条输入字节与事件数增长；
在未测量前无法判断是否需要摘要列表/按需读取/分页，也无法在改动后比较前后效果。
缺少可复现的样本生成与测量脚本。

## 2 目标可观察行为

1. `spikes/measure_agent_read.py` 生成三档样本（小/中/大：attempt 数、单条输入字节、事件数），
   在**系统临时目录**构造，不写仓库/环境根。
2. 每档记录：attempt 数、事件数、记录字节、响应体字节、wall 耗时 min/median/p95、CPU 时间、
   tracemalloc 峰值内存。
3. 输出为可复制的逐行 JSON + 口径说明；记录写入 STATUS（唯一数字源）。
4. 规格写入**触发阈值**（何时才引入摘要/按需读取/分页）；未达阈值不引入缓存。

## 3 不变量

1. 测量只读：不写 `ENV_ROOT`/`WORKSPACE_ROOT`/`loop/state`；样本用完即删。
2. 读取路径与 API 契约零改动；事件过滤与 `GET /api/runs/{id}/agents/{node}` 同口径。
3. 控制回执延迟不在本切片伪造：需要活跃 model 会话与真实 provider，本机不可运行，明确登记。
4. 数字只从脚本输出复制，不手算。
