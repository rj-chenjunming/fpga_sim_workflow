# 全站网页视觉重设计

契约：[Web UI §14](../spec/WEB_UI_SPEC.md#14-全站网页视觉系统2026-10-21)。用户选择专业清爽，后澄清仅现有浏览器网页，不开发桌面客户端或手机端专项适配；文中的桌面尺寸指电脑浏览器窗口。本轮同一执行者实施和验证，不声称独立复核。

| 切片 | 唯一 owner / 落点 | 验证门 |
|---|---|---|
| 视觉契约 | Lead / WEB_UI_SPEC §14 | 页面范围、桌面尺寸、状态与交互不变量 |
| 视觉系统与页面 | UI 实现者 / web 的共享 tokens、app.css、index.html、展示元数据 | 先跑浏览器特征基线；各页截图及桌面布局检查 |
| 旧界面配套 | UI 实现者 / legacy.html、legacy.css | 旧入口可访问、返回主工作台、既有控件可用 |
| 验证与归档 | 同一执行者分阶段 / tests/browser、STATUS、新证据 | 浏览器回归、静态 HTTP 冒烟、语法/补丁与新文档链接 |

1. 修改实现前运行现有浏览器特征测试，固定请求隔离、S0 表单、Agent 干预和草稿行为。
2. 先实施共享设计令牌与桌面导航框架，再统一配置、执行、闸门、S0、目录浏览和 Agent 窗口；保留现有元素 ID 和事件绑定。展示元数据只改变标题/栏目，不增加业务判据。
3. 以真实 Chromium 加载仓库静态页，API 使用明确的受控数据，验收 1280/1440/1920；截图包括有内容的运行/闸门/窗口及加载、空态、失败。修复布局问题后执行受影响回归。
4. 新增桌面视觉验证证据，记录命令、输出、截图与限制。不改冻结证据、kb 工具或环境资产，不连接真实模型/仿真；业务四道门和内网限制保留。

回退：视觉切片可按文件回退，保留 API、状态机和历史样张。无需更改运行数据或配置。
