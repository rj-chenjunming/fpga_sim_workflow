# S0 修订与工作台

仅修订附件 S0，并优化一版 UI。契约先行，见 [S0 契约](../spec/S0_ENVIRONMENT_SPEC.md)。本轮由同一实现者分阶段验证，不声称独立复核。

| 切片 | 唯一 owner / 落点 | 不变量 / 验证 |
|---|---|---|
| 现有行为 | 实现 owner / 既有浏览器特征与配置 API 测试 | 改代码前通过，保留闸门输入、切换与延迟回包行为 |
| S0-a | Host / `loop/host/s0.py` | 完整派生、整体 RTL 替换、指纹核验、输入不写；先失败用例 |
| API | 服务 / `loop/services/api.py` | 允许根、已有目标拒绝、失败显式、读取不改历史 |
| UI | Web / `loop/web/` | 默认 S0、双段进度、未接入项明确、响应式，保留现有运行与闸门 |
| 归档 | 实现 owner / STATUS + 新增证据 | 四道门分别记录，证据冻结 |

不重构既有编排拓扑，只扩展视图注册与绑定。S0-b 接口适配、三库驱动和新版执行入口未接入，UI、报告、状态均保留阻断。用户已说明内网仓库无法提供，不重新索要，不伪造真机数据。
