## 第一版：复用现有后端

| 切片 | owner / 落点 | 实施与验收 |
|---|---|---|
| P0 特征基线 | 前端实现 owner；既有 Agent/节点详情浏览器用例 | 固定入口、身份、原始状态、草稿、重复提交、取消与历史只读；采集桌面/窄屏截图及人工任务基线 |
| P1 统一面板外壳 | 同一前端 owner；app.js、agent-window.js、index.html、app.css | 集中选择状态；AI 节点与角色卡同入口；停靠/全屏、标签导航、焦点返回；U01/U09 |
| P2 信息与成果 | 前端 owner；新增纯展示适配层，服务投影 owner 复核字段 | 使用现有 Schema 和 Host 已接受结果；分开展示候选/校验/流程位置；U02/U03/U04/U10 |
| P3 控制与历史 | 前端 owner；复用现有控制 API，后端 owner 复核幂等/代次边界 | 按 available_actions 显示操作；草稿身份、回执、历史只读和终止确认；U05/U06/U08 |
| P4 刷新与交付 | 前端 owner；增量 DOM 更新和浏览器测试 | 断连/乱序/新结果、滚动、软键盘/窄屏、键盘和减少动画；U07/U09，完整受影响集回归 |

一次仅一个 owner 修改面板控制状态；展示适配层不能发送控制命令或重复判定业务通过。
先运行特征基线，保持行为提取再做交互变更，每片补可观察的先失败用例。
不通过快照重录掩盖状态/焦点/身份错误，截图变更必须说明与设计的对应关系。

## 第二版：独立依赖

- 版本对比：先确定两版输出及实际产物的身份/来源对齐，不将 N6 候选与落盘版本混比。
- 证据预览：先建立受限只读接口、类型/大小/编码限制和路径/秘密过滤，再做 UI；首版仅探测存在性。
- DSH 动态：依赖 [SPEC-08](../spec/DSH_AGENT_RUNTIME_SPEC.md) 的真实工具事件和能力探测，按 U11 验收。

## 验证、边界与回退

依次运行受影响浏览器与展示适配测试；涉及服务字段时补 API 合约测试。
按仓库要求执行软件层、kb 自测、端到端、文档门；内网资产缺失时明确记录未运行/失败，不造历史夹具。
UI 的受控验证不等于 live 模型、DSH 或真机仿真验收。同一执行者的测试不声称独立复核。

每片保留可回退提交，回退界面不重发任务、不回填或删除历史记录。生产热更新前处理在途表单与命令，
不能在提交途中替换面板控制器；历史 API 保持兼容。

本轮设计检查限于链接、代码围栏、文档路径增量和补丁格式；产品测试与用户任务测量留实施阶段。
结果写入 STATUS，设计推送不代表实现上线或环境发布。
