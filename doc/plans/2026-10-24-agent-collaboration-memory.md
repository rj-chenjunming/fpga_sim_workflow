# Agent 交接与记忆的 SpecDD 实施计划

依据用户授权的架构评估与 [H1 REV09（云端原 REV07）](../spec/SPEC-REV-09-20261025.md)。
唯一实现 owner 为本轮执行者；Host 持有事实、交接投影和校验，模型仅提出修改/复核意见，人持有业务闸门。

| 切片 | 落点 | 验收条件 |
|---|---|---|
| H1 来源交接 | host/agent_handoff、N6 请求输入 | 旧文本/顺序特征先过；稳定身份、重复条目、跨 run/尝试、坏引用红灯再实现；交接包随原请求封存 |
| H2a 回应交接 | 模型 Schema、Host 校验、N6/N8/N11 | 每个 ID 一条回应，绑定目标版本、候选 edit 引用；从封存 N6 重建并分发给对应复核者 |
| H2b 问题闭环 | 模型 Schema、Host 关联与状态投影 | 验收条件、跨轮问题关联、验证者关闭、过时/重新打开；作者不能自行关闭 |
| M1 本轮工作记忆 | 上下文构造层 | 从有效记录生成事实/决定/未解决项；来源可追、失效可解释、可重建；不另建业务权威 |
| M2 指令生命周期 | agent_control 与上下文构造层 | 本次尝试/节点返工/本轮任务作用域明确，撤销与替代、恢复不重放业务效果 |
| M3 跨运行经验 | agent_memory 的经验筛选 | 分离请求审计指纹与经验适用条件；精确事实严格绑定，通用建议经审批和依赖筛选 |

H1 先用原上下文/控制测试固定行为，提取原意见文本投影并复测，再增加结构化交接和来源拒绝用例。
回归请求审计、预算、N6/N8/N11 消费路径；四道门逐项记录，缺内网资产保持未完成。
历史云端切片不写冻结 kb，不安装新依赖，不触发 live 模型，不变更 DSH 准入；归档只增、只读、目录外 MD5。
H1 包含旧状态意见但不判其仍然有效，H2 才引入显式生命周期；避免将首片误称完整闭环。

H2a 依据 [REV10（云端原 REV08）](../spec/SPEC-REV-10-20261025.md)：先回归 H1/上下文/控制，保持行为提取源记录读取，
再加覆盖/引用/版本/非法记录和 N6→N8/N11 封存链红灯。Host agent_handoff 唯一持有交接校验，
model_steps 负责接线，node_schemas 与 prompts 同步字段语义。复核包不改变任何现有业务放行判据。
四门逐项实测，环境缺件保留；本轮不实现关闭台账、不安装依赖、不调用真实模型。

H2b 依据 [REV11（云端原 REV09）](../spec/SPEC-REV-11-20261025.md)：先跑 H1/H2a 与上下文/控制特征，
保持行为提取封存结果读取，再以红灯固定逐项验收/证据引用/原返工边/恢复/版本失效。
agent_review 持有复核分配、校验及回边投影；agent_handoff 持有共享记录核验与作者回应。
模型 Schema/prompts 与 model_steps 接线同步；不改冻结 kb，沿用返工预算与人工闸门。
对新快照一律重验，先实现可证明的保守规则，不引入猜测的相似度去重或自动经验晋升。
四道门逐项记录；环境失败先对照旧基线，证据冻结只增，无法推送时保留本地提交和恢复包。
