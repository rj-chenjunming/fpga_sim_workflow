## 1 C13：环境层用例在派生副本上跑通

**问题**：3 条用例（`test_archive_e2` ×2、`test_projection_and_frozen` ×1）要写 ENV_ROOT 下的
`SIMLIB_RUN/`、归档与数据根；本机 ENV_ROOT 只读 ⇒ 直接跑必红，软件层入口默认 `-m "not env_layer"` 排除，
长期只能"登记为环境缺件"。

**判据**（不读源码也能判）：一条命令能跑这 3 条并给出通过数；**跑完原 ENV_ROOT 零写入**；
副本可复用、可清理。

**实现**：`loop/spikes/run_env_layer_checks.sh`
- 用 `kb_lib`（唯一解析器）解析 ENV_ROOT，`cp -a --reflink=auto` 成派生副本 `<repo>/.env-copy`（2.6 GB），
  `chmod -R u+w` 后以 `LOOP_ENV_ROOT=<副本> LOOP_WORKSPACE=<副本>/kb` 跑 `-m env_layer`；
- **零写入自证**：跑测试前建 marker 文件，跑完 `find <原ENV_ROOT> -newer <marker>` 必须命中 0，否则 exit 3；
- `--reuse` 跳过复制、`--cleanup` 删除副本；数据根取副本内 `kb`，满足
  `test_projection_and_frozen` 的「数据根位于 ENV_ROOT 之内」布局要求。

**实测**（STATUS §83.2）：`3 passed`；`find -newer` 命中 **0**；冷启动复制 51 s、热启动整轮 10 s。

## 3 C10：I4 72 条冲突 —— 先补"能记录裁决"的机制，再由人逐条裁决

**事实**（命令输出见 STATUS §83.3）：`conflicts.json` 72 条，**全部** `status=open`、
**全部** `blocks_release=true`；分类 NUM 13 / NAME 10 / ADDR 10 / MISS 9 / RT 7 / RW 6 / BITS 5 /
SCOPE 4 / 复合 7。I4 消费链只读 `blocks_release`（4 处代码 + 1 处投影）⇒ **改接口文档不会解除阻断**。

**已有资产**：`<ENV_ROOT>/kb/adjudication/C_conflicts_triage.md`（md5 `bc862a6855cf48f5af4a6a70294f5c87`，
764 行）已经把 72 条逐条摘要、可复现分组（G1–G9 / 根因批 B1–B4）、必须逐条看的 19 条、跨章节 17 条、
与 `access_restrictions.json`/`pending.json` 交叉的 22/23 条整理完，并给出 schema 逐项对照。

**四个工程缺口**（该文件的 §6.4，结论：**不改 schema**）：

1. 无 `ruled_at` 字段（`additionalProperties:false` ⇒ 不能私自加键）⇒ 时刻并入 `resolution` 文本，或授权加字段；
2. 条件不变式（`status=ruled ⇒ resolution` 必填、`resolution_kind=human ⇒ blocks_release=false`）
   schema 表达不了（`kb_lib.validate` 明确拒绝 `if/allOf`）⇒ **只能由 Host 工具强制**；
3. **没有任何 Host 工具能写 conflicts 裁决**（`kb_lib` 的 human-only 与锚机制只覆盖 `gates.json` 的三道闸门）；
4. 重跑 `kb/tools/n1_conflicts.py` 会把裁决复位（第 287/292 行硬编码 `open` / `true`）
   ⇒ 裁决必须**外置持久化**（推荐 `conflicts/adjudication.json` + 抽取时合并）。

**切片（2026-10-27 已获授权，C10-a 已完成）**：

- **C10-a 机制**（写 `kb/tools/**` 冻结目录，需显式授权 + 留证）——**已完成**（STATUS §84；md5 前后对照与 `PASS=28` 自测见该节）：
  新增 `kb/tools/adjudicate_conflicts.py`（human-only：`--actor human:<name>` 必填、拒绝 `model/host` 自签、
  写 `conflicts/adjudication.json` 只增不改、每条带 `resolution/actor/kind=human/at` + sha256 锚、
  复用 `kb_lib.check(obj,"conflicts")` 校验）；
  改 `kb/tools/n1_conflicts.py` 使其**合并** `adjudication.json`（抽取可复现 + 裁决不丢）。
  留证：两文件改前/改后 md5 + 自测脚本，写入 STATUS。
- **C10-b 人工裁决**：按 triage 的分组批量裁决（每组一个结论 + 逐条 `id` 列表），人签署 actor；
  19 条"必须逐条看"的单独过。
