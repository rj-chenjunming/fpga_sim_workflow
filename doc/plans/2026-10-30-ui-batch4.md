## A 图标 SVG sprite

- **现状**：23 个 Unicode 码位 / 54 处承担图标作用（`index.html` 15、`app.js` 14、`s0.js` 7、`legacy.html` 12、
  `node-detail.js` 3、`app.css` 3），且一符多义（`▧` 导航「环境准备」+「基线」；`◇` 导航「人工闸门」+ 空态插图；
  `↗` 外链/下载/页内浮层/同页跳转；`…` 状态与文案省略号）。
- **做法**：`index.html` 内联 `<svg id="iconSprite">`（`<symbol>`，`viewBox="0 0 16 16"`，路径纯线条 `currentColor`），
  页面与 JS 用 `<svg class="icon" aria-hidden="true"><use href="#icon-…"/></svg>`。
  **硬约束（既有测试卡）**：① 内联 SVG 不写 `xmlns`（`tests/test_web_smoke.py:31`、`tests/test_api.py:59` 卡 `http://` 零出现）；
  ② JS 不用 `createElementNS`（同条）；③ CSS 伪元素不用 `url()`/`mask`（`tests/browser/test_ui_visual_20261030.py:261`），
  因此 `.empty:before` 的装饰图标改结构挂内联 SVG，`.aw-detail` 的 `▸▾` 死规则（`app.css`）删除。
  ④ 字号只取 §14 阶梯、不新增字号；`test_ui_typography.py` 扫描数只增。
- **范围例外（登记）**：`legacy.html` 12 处**不迁移**（旧界面存档；`⚠/⛔` 仍依赖 emoji 字体）。进 STATUS 未做清单。
- **验收**：新增 `loop/tests/test_ui_icons.py`（软件层）：symbol 表与 `use` 引用一一对应、无死 symbol、
  组件层不再出现被替换码位、无 `xmlns`/`createElementNS`/`url(`；浏览器门 0 failed；三视口无水平溢出、侧栏几何不回退（A10）。

## C 闸门窗格上限放宽（契约变更，已获授权）

- **规格先改**：`WEB_UI_SPEC.md` §14 新增「闸门两栏上限放宽（2026-10-30 增补）」，
  `clamp(300px, calc(100dvh - 340px), 720px)` → `clamp(300px, calc(100dvh - 300px), 860px)`；A11 口径不变。
- **依据（§14 增补已写入）**：实测 gate chrome ≈300.6px；1080 视口旧上限 720 自截断 20px；上界只影响高视口。
- **不改首屏**：`#gateMaterial` 的 y 由上方块高决定，1280×720 仍在首屏外（缺口 108.3px），
  需要折叠非当前阶段（结构变更）——**不在本批做**，进 STATUS 未做清单。
- **实现**：`app.css` `.gate-pane` 的 `--gate-pane-max-h`；`tests/browser/test_gate_panes.py`
  的 `PANE_MAX_H_OFFSET 340→300`、`PANE_MAX_H_MAX 720→860`（先改常量→红，再改 CSS→绿）。
- **验收**：`test_gate_panes.py` 全绿（它断言计算值 = 推导值、上限一致、内容不足不滚、跨轮询保持）；
  运行时读数复测三视口窗格高（420/600/780）与 `#gateMaterial` 的 y 不变。
