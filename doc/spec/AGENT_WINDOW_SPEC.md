# Agent 工作窗口与运行干预

## 范围和 owner

从 Agent 卡片进入工作窗口，绑定 run/node/session/attempt，查看实际输入、模型/替身、结果、Host 校验与节点事件。当前角色为 N3/N6/N8/N10/N11/N12 模型调用，不声称具备 DSH 独立终端、并行调度或持久聊天。没有模型隐藏推理或 token 流，输出返回后显示，等待时显示真实状态和事件。

Host `loop/host/agent_control.py` 唯一管理活跃请求、命令去重、取消及重发。`agent_memory.py` 继续独占原请求/结果记录。干预仅发生在 `run_model_node` 请求边界；业务副作用、仿真和闸门仍由现有 owner 管理。无活跃调用的历史窗口只读，不重放任务。checker 的 N8/N10 分别选择。

## 动作

| 动作 | 允许状态 | 实际效果 |
|---|---|---|
| steer | working / paused | 保存指令，取消本地旧请求并等待退出，新增 attempt 重发；暂停时发送并恢复 |
| pause | working | 取消本地请求、丢弃响应，停在请求边界，不进入消费者 |
| resume | paused | 用原事实和已有指令发新请求，不是继续远端同次推理 |
| terminate | working / paused | 取消请求，节点抛显式错误，既有编排收敛 failed，不可恢复已终止节点 |

取消只保证应用不消费旧响应，远端停止取决于 provider。取消未完成不重叠重发或假报暂停；取消超时使节点显式失败。请求完成后拒绝控制，不能回滚业务写入。命令与结果并列完成时，已接受的干预优先于未消费响应。

每命令必带 `human:<name>` 元数据、`request_id`、目标 `session_id` 和 `expected_revision`；steer 需非空且有限长度 message。human 元数据不是身份认证。同 ID 同内容重试幂等、不同内容冲突；旧会话/版本、无活跃调用、非法动作均在写前拒绝；pending 时拒绝另一命令。接收与应用分别记账，UI 不将接收当成生效。

人工指令只加入新 attempt 的 `human_interventions`，不改原事实、offered、Schema、校验或闸门，仍检查输入预算。它是本会话工作记忆，不自动成为跨运行经验。

## 审计与恢复

运行目录 agent_controls 下按节点/session 顺序独占创建会话目录，会话及事件文件只增不改并附指纹。审计写失败不得确认成功或消费不明结果。进程注册表只标记当前活跃请求；外部取消、结束、异常必须注销并收敛子任务。

重启后窗口可读历史，但旧会话不可控制；中断按既有运行恢复机制显式失败，不自动恢复暂停或重发。持久暂停/续跑需后续 TriggerFlow 恢复契约，UI 不暗示已有该能力。

## API 与 UI

- `GET /api/runs/{run_id}/agents/{node}?attempt=<sequence>`：live 会话及 available_actions、尝试列表、选中请求/结果、控制记录、相关事件。先校验历史指纹，损坏显式报错；无记录空态，不调用模型。
- `POST /api/runs/{run_id}/agents/{node}/control`：提交命令并返回接收回执。数据错误 400、actor 错误 403、过期/不可控 409、未知运行/节点 404。动作只消费服务端枚举。
- 模态窗口支持键盘，关闭不停止任务；切换运行关闭旧窗口、废弃旧回包。刷新不替换输入 DOM，提交中不重复发送。409 保留草稿；回执不能污染其他会话。仅真实状态轮询，没有虚构进度。
- 能力事实（F02-c）：`GET` 响应带服务端 `capabilities`（四维：实现/依赖/本次执行方式/验证范围），
  窗口与角色卡消费同一来源、共用同一格式化实现；`null` 显示「未知」，`standin` 不显示为真实完成。
  四维按**节点最新执行**投影；选中历史 attempt 时，该 attempt 的实际方式以它的 `result.status`
  （`standin`/`validated`…）呈现，不把它误读成四维中的「本次执行方式」。
- 输入/输出安全文本渲染，不变成 HTML 或命令；只读受管理运行中的固定节点记录路径，不接受任意文件路径。

## 验收

先固定模型调用/记录与 UI 会话特征，再做保持行为的单次调用函数提取。新增受控 provider 用例先失败，验证指令消费、暂停/恢复/终止、不重叠、竞态、预算/校验、幂等/过期/跨运行拒绝、审计失败、取消清理及历史核验。浏览器验证卡片进入、节点切换、输入不丢、提交身份、409、关闭/切换后旧回包、无记录及窄屏。内网不可用时不冒充真实模型/仿真验收。
