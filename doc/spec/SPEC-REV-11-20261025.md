## 本机修订验收

逐项复核中的 rework_index 必须指向模型本次返回的原始列表位置。Host 不得通过过滤非法条目、
将非字符串强转为字符串或把标量转换成列表，使原本非法的返工要求变成可消费的闭环证据。
提供 review_assignment 时，对 N8 must_fix / N11 rework_requests 的完整列表先严格校验，再核验逐项关联；
即使没有 assigned 问题，也拒绝非法新要求。旧调用未提供 assignment 的兼容行为保持。
重建封存复核使用同一判据；不能把格式错误或矛盾的封存结果降级为 stale_review。

N6 替身后的回边必须保留已封存请求中的原问题身份，并标记为待复核；不能因替身无可信回应而清空历史。
请求有 assignment 时校验其与 run/targets/handoff 一致，重建不采纳替身作者的声明或候选身份。
