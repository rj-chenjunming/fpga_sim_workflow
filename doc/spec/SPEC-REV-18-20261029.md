## 1 范围与唯一判据

- 「人参与反馈次数」= **该 attempt 的 DSH 会话里由人发出的消息条数**（D3 旁路会话：人在实例 GUI 里说的话）。
- **判据唯一实现**在 `host/agent_backends/dsh_sdk.py`（会话日志的唯一解码者）。界面与 `services/instance_proxy.py`
  **只透传数字**，不得重算、不得另写一份"什么算人"的判定（红线 8）。
- 不声称：不声称这是"业务反馈质量"或"人审次数"的判据；不声称覆盖 loop 侧 steer/pause（那是
  `agent_controls` 的人工指令，已由窗口上方「指令回执与生效」三列表呈现，两者**不是**同一口径）。

## 2 解析口径（`dsh_sdk`，只增字段）

`sesson-copy.facts`（= `CompactionFacts` 的 `asdict`）**只增**两个键：

| 键 | 类型 | 含义 |
|---|---|---|
| `human_messages` | int | 人发出的消息条数（去重后） |
| `human_messages_basis` | str \| null | 计数依据（可核）：`source.kind=user,dedupe=id\|rpcId,skipped=N` |

计数规则（**唯一实现**）：

1. 只看两类事件：`user/message` 的 `data`，与 `agent/inbox/spliced` 的 `data.inserted[]`（D3 插入消息）；
2. 条目 `source.kind == "user"` 才算人发的；其它来源（`time-context` / `system-reminder` / `runtime-context` /
   缺 `source` / `source.kind` 未知）**一律不计**（不猜）；
3. 去重键 = `id`，缺则 `rpcId`（同一条消息在 `agent/inbox/spliced` 与 `user/message` 各出现一次 ⇒ 只计 1）；
4. 两个键都没有的条目**不计数**，但计入 `basis` 的 `skipped=N`（宁可少算也不编数）；
5. 源不可用（缺 zstd / 解压失败 / 非 UTF-8）⇒ 沿用 `availability="unavailable"`：`human_messages=0`、
   **不出数**（界面走"执行结果不可用"分支，不显示 0）；
6. 历史日志不回填、不改写。

## 3 界面（REV-17 §2-4 只增）

`#awEmbedFacts` 的执行结果行在 `剪枝 …` 之后追加 `人参与 N 次`：

- `facts.human_messages` 是数字 ⇒ 显示该数字（`0` 是真实值，显示 0）；
- 字段缺失/非数字（旧服务端/旧记录）⇒ 显示 `人参与 未知`（不折成 0）；
- 不新增第二套判据、不读其它端点。

## 4 验收（新增 `OBS-10`）

| 编号 | 判据 | 方式 |
|---|---|---|
| `OBS-10` | ① 单条 `source.kind=user` ⇒ 1；② 同 `id` 的 spliced + user/message ⇒ 1；③ 不同 `id` ⇒ 2；④ 非人来源（`time-context`/`system-reminder`/`runtime-context`/缺 kind）⇒ 0；⑤ 缺 `id` 时用 `rpcId` 去重；⑥ 两者皆缺 ⇒ 不计且 `skipped` 记录；⑦ 源不可用 ⇒ 0 且界面不显示 0；⑧ 界面：有字段显示 `人参与 N 次`、缺字段显示 `人参与 未知` | 单测 + 浏览器 |

## 5 未决（只增）

- `source.kind` 的取值集合由上游 DSH 定义，本规格只认 `user`；上游新增来源（如"多模态语音"）需单独确认后再纳入。
- loop 侧人工指令（`agent_controls` 的 steer/pause）与本口径并列不合并；若将来要「人参与总览」需另立判据。
