# 节点实现

本目录承载闭环节点的执行逻辑，`main_flow.py` 仍负责唯一的顺序、分支、停放和返工拓扑。原 `chunks` 中同名入口暂时保留：当前 TriggerFlow 版本以源码位置生成节点身份，入口及占位行用于兼容指定版本的快照；当前对齐 f710079，旧拓扑快照迁移仍待验证。不要随意移动或压缩。共享的 Host 校验、模型请求和台账功能仍由原唯一实现提供，节点入口显式注入所需依赖。

| 模块 | 职责 | 主要消费方 |
|---|---|---|
| `n0`、`n1`、`n2` | 初始化、快照、差异 | N3、G1、N5 |
| `n3` | 模型差异摘要 | G1 |
| `gate_enter`、`gate_resume` | G1/G2/G3 人工中断及签署后处理 | N5、N6、N15、HALT |
| `n5` | 影响分析 | N6、N12、N15 |
| `n6_author`、`n6_apply` | 模型修订建议、Host 沙箱应用 | N7、N8、N9 |
| `n7`、`n8` | 编译与静态复核 | N9 或返工 |
| `n9_submit`、`n9_park` | 提交作业、停放并读取结果 | N10、N11 |
| `n10`、`n11`、`n12` | 对账、证据守护和报告 | G2 或返工 |
| `n15_select`、`n15_run` | 回归选集和运行 | N16 |
| `n16`、`halt` | 晋升前校验或显式终止 | 运行终态 |

`host/simulation_adapter.py` 是现有环境的进程内能力边界，覆盖暂存输入、用例路径、SystemVerilog 事实提取、编译、仿真命令及日志定位。当前只有默认环境实现：配置选择、其他环境与自定义适配器跨重启恢复尚未接入。模型负责语义输出，Host 和 kb 仍负责身份、准入、数据写入及判据；人工闸门仍由人决定。
